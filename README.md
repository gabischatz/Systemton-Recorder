# SystemtonRecorderGUI

## Beschreibung

**SystemtonRecorderGUI** ist ein Makro für den **SpeedCommander**, mit dem eine grafische Oberfläche zum Aufzeichnen von Systemton gestartet werden kann.

Das Projekt ist dafür gedacht, Arbeitsabläufe rund um die Aufnahme von Systemaudio einfacher zu machen. Statt einzelne Schritte manuell auszuführen, kann das Makro direkt aus dem SpeedCommander heraus gestartet werden und dient damit als bequemer Einstiegspunkt für die zugehörige Aufnahme- oder Hilfsanwendung.

## Zweck des Projekts

Das Makro soll dabei helfen,

- eine zugehörige GUI schnell aus dem SpeedCommander zu starten,
- Arbeitsabläufe zur Audioaufnahme zu vereinfachen,
- wiederkehrende manuelle Schritte zu vermeiden,
- Dateien und Aufnahmefunktionen besser in den eigenen Workflow einzubinden.

## Einsatzbereich

Das Projekt eignet sich vor allem dann, wenn Aufnahmen von Systemton vorbereitet oder gesteuert werden sollen und der SpeedCommander bereits als zentrale Arbeitsumgebung genutzt wird.

## Datei

- `SystemtonRecorderGUI.scmac`  
  SpeedCommander-Makro zum Start der zugehörigen GUI bzw. Funktion.

## Verwendung

1. Die Datei `SystemtonRecorderGUI.scmac` im SpeedCommander einbinden.
2. Das Makro im SpeedCommander aufrufen.
3. Die grafische Oberfläche bzw. die verknüpfte Funktion starten.
4. Danach die gewünschten Schritte zur Aufnahme oder Weiterverarbeitung ausführen.

## Hinweis

Je nach Aufbau des Projekts kann es erforderlich sein, dass weitere Dateien im gleichen Ordner liegen oder feste Pfade angepasst werden müssen.

## Ziel

Ziel des Projekts ist eine möglichst einfache und schnelle Nutzung über den SpeedCommander, ohne dass die zugehörigen Funktionen jedes Mal manuell gesucht oder gestartet werden müssen.
